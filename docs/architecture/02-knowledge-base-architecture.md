# 知识库架构：GBrain 存储、检索与快照

GBrain 是独立知识基础设施，只负责可信知识的导入、索引、检索、存储和快照。经验提炼链路见 [Diff 流程架构](04-diff-workflow-architecture.md)，任务推理链路见 [中台铁三角架构](03-triangle-agent-architecture.md)。

---

## 1. 定位

GBrain 为中台提供可检索的事实、规则、原则和可信法则。它是知识底座，不是流程编排器，也不是审核工作台。

## 2. 知识资产类型

| 类型 | 来源 | 用途 |
|---|---|---|
| 平台事实 | 平台说明、页面规则、字段定义、产品规范 | 约束方案不偏离真实平台能力 |
| 业务规则 | 业务流程、准入条件、审批规则、异常处理要求 | 支撑方案生成和异常校验 |
| 架构原则 | 历史裁决、技术取舍、可用性和一致性要求 | 支撑架构评审和技术取舍 |
| 可信法则 | 审核通过并设置作用域的经验 | 在后续任务中高优先级注入 |

## 3. 能力边界

GBrain 负责：

- 接收知识材料并完成解析、切分、索引。
- 按任务目标、业务域、模块、场景和作用域检索知识。
- 保存已经审核通过的可信法则。
- 生成知识快照，支持中台降级运行。
- 记录知识版本、来源、作用域和撤销状态。

GBrain 不负责：

- 任务推理、角色协作和质量门禁。
- 经验提炼工作流和人工审核。
- 终稿交付链路。

## 4. 知识导入

知识冷启动通过两条路径完成：

1. **前台上传**：业务人员通过知识管理页上传材料，适合持续维护。
2. **管理员批量导入**：管理员导入历史资料目录，适合初始化或迁移。

导入完成后，GBrain 返回索引状态、失败原因和可检索范围。

## 5. 检索接口

中台按任务目标向 GBrain 发起检索：

```text
检索输入：任务目标 + 业务域 + 当前阶段 + 争议点 + 作用域
检索输出：事实片段 + 可信法则 + 来源 + 版本 + 置信提示
```

检索结果必须保留来源和版本，方便后续审查和用户追溯。

## 6. 可信法则存储模型

每条可信法则至少包含：

- 法则内容。
- 来源任务和证据摘要。
- 作用域：全局、业务域、模块或特定场景。
- 审核状态。
- 审核人和审核时间。
- 版本号和撤销记录。

GBrain 只接收审核通过的可信法则，不接收未审核的候选法则。

## 7. 降级快照

GBrain 不可用时，中台读取最近一次可信快照：

1. 前台提示知识库不可用或可能非最新。
2. 中台记录快照时间和知识版本。
3. 输出中避免把未确认事实写成确定结论。
4. GBrain 恢复后补偿记录失败检索和待同步事件。
